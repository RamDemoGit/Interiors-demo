# Client logos / images

Drop the client images here (PNG, JPG, WebP, AVIF or SVG).
They appear automatically on the Clientele page as a moving strip; clicking one opens it full size.

- Name files in the order you want them: `01-first-client.png`, `02-second-client.png` ...
- The file name (without the number) becomes the caption: `01-acme-interiors.png` -> "Acme Interiors".
- Only add logos of clients who have given permission to be shown.
